#  Mohammed Naif — Portfolio Website

This is my personal portfolio website showcasing my skills, projects, and contact information.
The site is fully responsive and built with plain **HTML**, **CSS**, and **JavaScript** — no framework.
Its design language follows the current (2026) Nothing website: light grey canvas, NType82 headlines,
Geist / Geist Mono text, dot-matrix accents, frosted floating header and a light/dark theme.

---

##  Live Demo
**https://naifportfolio.dev**

---

##  Features
- Text-only hero with a scroll-linked, word-by-word headline highlight
- Floating frosted header with an expanding menu panel
- Project showcase (swipeable carousel on mobile, grid on desktop)
- Experience, skills and about sections
- Contact form powered by EmailJS
- Light / dark theme that follows the system setting and remembers your choice
- Smooth scrolling (Lenis), scroll reveals, reduced-motion support
- Downloadable resume
- Custom domain with HTTPS

---

##  Technologies Used
- **HTML5**
- **CSS3** (custom design tokens, no CSS framework)
- **JavaScript**
- **Lenis** (smooth scroll), **EmailJS** (contact form)
- **Bootstrap Icons** and **Devicon** (icons)
- **GitHub Pages** (Hosting)
